## What this major is

A small movable frame that points the way to a target and shows the distance under it: Skill
Master's own waypoint arrow (owner feedback rounds 6 and 7), moved into the library on the owner's
decisions of 2026-11-14 (Skill Master `docs/superpowers/plans/2026-11-14-feedback-round8.md`, row
L1). It rotates the art toward the target, fades its color from a far color to a near color by
distance, scales, drags (handing the new point to the host), and has a sample for test mode. Five
looks ship: **Flat**, **Ridge**, **Raised** (the default), **Faceted** and **On the ground**, the
top artboard of the owner's mockup of 2026-11-14.

It owns no SavedVariables: the host keeps the arrow's five settings at its own paths (the settings
rows below) and hands them over with `Configure`. It is never secure and calls nothing protected,
so it stays shown and movable in combat. Skill Master is its one consumer; the one-consumer
promotion is a row in the repo's register (`CLAUDE.md`, *Documented deviations*).

### Measuring

Each measure (on show, then every `THROTTLE` seconds from an OnUpdate armed only while the frame
shows, and disarmed by `Clear`, arrival and `Suspend`) reads the player's world position and facing
and the target's world point. World coordinates: x points north, y points west.
`GetPlayerFacing()` is radians counter-clockwise from north. The rotation is the bearing less the
facing, and `Texture:SetRotation` turns counter-clockwise for a positive angle, so the art, drawn
pointing up, turns toward the target.

- **No facing** (nil, or a secret value, as in instances): the art hides and the distance stays.
- **No distance** (another instance or continent, a secret or unknown position): the label shows
  alone, in the skin's `muted` role (dimmed to 0.6 without a skin).
- **Arrival**: within `arrive` yards the target is cleared, the arrow hides and `onArrive(spec)`
  runs.

### The looks

Every look is a **body** tinted with the color and an **overlay** drawn over it untinted, so any
color works: a texture tinted with `SetVertexColor` is multiplied by the tint and can never draw
lighter than it, so the highlights (and the outline, `#1a1410`) live in the overlay.

| Style | Body | Overlay | Turns by |
|---|---|---|---|
| `flat` | `arrow-fill` | `flat-overlay` (the outline) | `SetRotation` |
| `ridge` | `arrow-fill` | `ridge-overlay` (lit left half, shaded right half) | `SetRotation` |
| `raised` | `arrow-fill` | `raised-overlay` (tip-to-tail light, a rim on the leading edges) and `raised-shadow` under it, anchored `SHADOW_OFFSET` down and right so the light stays put while the arrow turns | `SetRotation` |
| `faceted` | `arrow-fill` | `faceted-overlay` (four facets meeting at a peak) | `SetRotation` |
| `ground` | `ground-body` | `ground-overlay` | `SetTexCoord`: one of 72 frames of the angle sheet, the nearest 5 degrees (`GroundFrame`) |

The ground cell is drawn 50 x 34.375 px at scale 1, centered 5.1875 px under the art box's center.
The color is `Mix(far, near, Fade(yards, near, far))`, where far and near are the skin's
`SKIN_FAR` and `SKIN_NEAR` while `useSkinColors` is on and the instance's `skin` answers them, else
the configured `farColor` and `nearColor`.

## The settings rows (`WaypointArrowSettings.lua`)

`SettingsRows(opts)` answers ordinary **path** schema rows for the host's own schema, in this
order: Style (`string`, `values` = `StyleValues(L)`), Use the skin's colors (`bool`), Far color and
Near color (`color`, `hasAlpha = false`, each `disabledIf` the Use the skin's colors path), Scale
(`number`, `SCALE_MIN` .. `SCALE_MAX`, step `SCALE_STEP`, `commitOn = "change"`). Every row carries
`path`, `key` (the arrow setting it holds), `type`, `default` (from `DEFAULTS`), `label`, `desc`,
`page`, `group`, `subgroup` and `onChange(value)`.

| `opts` field | Meaning |
|---|---|
| `paths` | `{ style, useSkinColors, farColor, nearColor, scale }`: the host's path for each setting. A setting with no path has no row |
| `page`, `group`, `subgroup` | Copied onto every row |
| `L` | Overrides `SETTINGS_STRINGS` by key, read with rawget |
| `encodeColor(r, g, b, a)` | Shapes the color rows' defaults the way the host stores colors; `{ r, g, b, a }` without it |
| `arrow` | An instance: each row's `onChange` calls `arrow:Configure({ [key] = value })` first |
| `onChange(key, value)` | Called after, on every change |

`SETTINGS_STRINGS` keys: `STYLE`, `STYLE_TIP`, `STYLE_FLAT`, `STYLE_RIDGE`, `STYLE_RAISED`,
`STYLE_FACETED`, `STYLE_GROUND`, `USE_SKIN`, `USE_SKIN_TIP`, `FAR`, `FAR_TIP`, `NEAR`, `NEAR_TIP`,
`SCALE`, `SCALE_TIP`.

## Adopting it

```lua
local Arrow = LibStub("LibKa0s-WaypointArrow-1.0", true)
local PATHS = { style = "waypoints.arrowStyle", useSkinColors = "waypoints.arrowSkinColors",
  farColor = "waypoints.arrowFar", nearColor = "waypoints.arrowNear", scale = "waypoints.arrowScale" }

local arrow = Arrow:New({
  addon = "MyAddon", name = "MyAddonWaypointArrow", skin = "MyAddon",
  point = db.profile.waypoints.arrowPoint,
  onMoved = function(p) db.profile.waypoints.arrowPoint = p end,
  canDrag = function() return not db.profile.locked end,
  onClick = function(_, button) if button == "RightButton" then clearWaypoint() end end,
  onArrive = function(spec) print("You have arrived: " .. spec.label) end,
})
arrow:ConfigureFrom(GetSetting, PATHS)              -- at load, and after a profile switch or reset

RegisterSchemaRows(arrow:SettingsRows({ paths = PATHS, page = "waypoints", group = "Waypoints",
  encodeColor = function(r, g, b, a) return { r, g, b, a } end }))

arrow:SetTarget({ mapID = 1429, x = 0.42, y = 0.65, label = "Trainer" })   -- show
arrow:Clear()                                                             -- hide
```

The host's profile defaults hold the five values (from `Arrow.DEFAULTS`) at `PATHS`, and the
saved point beside them. A skin change reaches a shown arrow on its next measure; `arrow:Apply()`
repaints at once.

## What a consumer owes

- The art ships whole with the payload, under `media/waypoint/`; nothing is declared.
- A host that stubs this major for a degraded load stubs `New` answering an instance whose methods
  are no-ops, and `SettingsRows` answering `{}`.
