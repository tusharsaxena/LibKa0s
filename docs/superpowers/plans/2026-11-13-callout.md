## Design

### The module

- `LibKa0s/Callout.lua` (major `LibKa0s-Callout-1.0`, minor 1, needs Core ≥ 1; Media, Skin, Options
  optional at call time) and `LibKa0s/CalloutSettings.lua` (the settings section, paired minor).
- `Callout:New(d)` answers an instance. Descriptor: `name` (frame name), `db` (getter of the host's
  profile table the instance reads and writes its settings into), `skin` (optional, for "Skin font"),
  `debug` (optional `debug(tag, msg)`), `soundsBase` (the folder holding the vendored packs; defaults to
  the library's own `media/sounds/callout`).
- **Timing (the reason this exists):** `inst:Countdown{ endsAt = <GetTime() value>, from = n (≤ 20),
  finish = "GO" | key | false, onTick = fn(n), onDone = fn }`. The shown number is
  `math.ceil(endsAt - GetTime())`, read on the frame (OnUpdate) while a countdown runs, so the number
  flips the same frame the true remaining time crosses the integer. A consumer drawing its own clock
  reads the same `endsAt`, so both agree. No AceTimer chains, no drift. `inst:Cancel()`, `inst:Running()`.
- **Stock texts** (key → shown text, kind, voice line): READY, GO, START, STOP, WARNING, ERROR, DONE,
  FINISH, NEW_BEST, PAUSE, RESUME, CANCELLED, plus PULL, INTERRUPT, MOVE, DEFENSIVE, REBUFF, EXPIRING,
  UPGRADE, TIME_UP, VICTORY, FAILED, LAST_TEN; numbers 1–20. Kinds: number, info, go, stop, warn, error,
  each with a default color the player can change.
- `inst:Show(keyOrSpec, opts)`: a stock key, or `{ text, kind, sound (file path), voice = false, hold,
  anim }`. A custom text with no sound may be spoken by in-game TTS when the player chose Game TTS.
- **Look:** font (registered LSM fonts plus "Skin font" and "Game default"), size 32–200, outline
  (none, outline, thick, monochrome), shadow (on, x, y), per-kind colors, glow behind the text (off,
  soft, strong), animation, position (saved point; unlock-to-move with a drag handle; never takes the
  mouse while locked). Animations are built from AnimationGroups (alpha, scale, translation), no
  OnUpdate per animation.
- **Sound:** voice = one of the bundled packs, "Game TTS", or off; TTS voice picker from
  `C_VoiceChat.GetTtsVoices()`; channel (Master, SFX, Dialog); "speak numbers from" N (1–20). Missing
  files (a consumer that pruned a pack away) fall back silently to no voice, logged once.
- **Settings section:** `inst:BuildSettings(parent, opts)` builds the Look / Sound / Texts rows with
  the host's LibKa0s Options instance (when given) and a live preview; `inst:Preview()`.
- No SavedVariables of its own (the host's `db`), secret-free (no meter values pass through it),
  stand-down aware (`inst:Suspend()` / `inst:Resume()` hide and cancel).

### The sound subset

- Packs live at `LibKa0s/media/sounds/callout/<voice>/<line>.ogg` with a per-voice `LICENSE`/`CREDITS`.
- A consumer declares, directly under its icon line in its root `CLAUDE.md`:
  `LibKa0s sounds: none.` / `LibKa0s sounds: all.` / `LibKa0s sounds: callout/<voice>, ...`.
  **No line means none** (sounds are opt-in: only a Callout consumer needs them).
- `tools/prune-icons.lua` gains the sound step (one tool, so every existing re-vendor flow prunes both);
  `testkit/vendor_sync.lua` parses the line and holds a consumer's `media/sounds/` to it.

### Standard (upstream)

- library-stack-§7: a `LibKa0s-Callout-1.0` table row; a *The sound subset* rule beside *The icon
  subset*; §3's carve-out sentence names sounds too; anti-patterns and the changelog/version per that
  repo's own release rules.
