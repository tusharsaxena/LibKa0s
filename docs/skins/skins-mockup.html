Ka0s Skins Mockup

Design reference for the LibKa0s skin module (2026-10-25). Each skin draws the same surfaces: a window (title bar, close, tabs, search, dropdown, buttons, table, scrollbar, footer), a settings page (nav rail, heading, checkboxes, slider, dropdown, color swatch, drawer), a confirm dialog, a tooltip and a HUD meter. Fonts are web stand-ins; WoW has no blur, so Glass is translucency only. The token tables in this file's script were the starting point for LibKa0s/Skins/*.lua.
